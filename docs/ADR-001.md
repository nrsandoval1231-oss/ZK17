# ADR 001: Static content and motion boundary
Status: accepted within owner master directive.
Use Next.js App Router static export on Cloudflare Pages. No request runtime, database, authentication or CMS. Editable typed data remains in content/site.ts; server construction filters records before serializing approved props.
Interactive browser responsibilities: menu/dialog state and GSAP choreography. Native document scrolling remains authoritative. Desktop pinned scenes are matchMedia-controlled and removed for mobile/reduced motion; content remains readable without JS. Media uses local responsive picture assets and on-demand video.
Public release is a separate build decision. Review assets may be owner-authorized screenshot crops but remain rights-pending, visibly labeled and blocked from release mode. Unannounced commitment content never enters the repository or public bundle. No analytics or externally hosted fonts.
Consequence: content changes require a rebuild, which is appropriate for this initial site and allows every publication to bind to a reviewed commit/export. Original-photo and approved-film updates fit the same scene components.
