# Director's cut — Task 1 implementation report

Implemented a scroll-scrubbed hero with approximately 15 stable viewport heights of pin distance on desktop and touch, with darkness, sequential lamps, layered smoke, a dark photo silhouette, standing portrait, individual game-action/rear/white-jersey photographs, and a final statement hold. The cinematic sword was removed; the header and film implementation were not edited. The pin uses the hero's small-viewport height plus header padding for distance rather than the dynamic `innerHeight`, and refreshes on orientation change. Reduced motion and the unenhanced document retain the complete static composition. Visual effects use transform/opacity, gradients, and a deterministic small raster smoke texture; no athlete or anatomy was generated.
